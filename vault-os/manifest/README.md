# Source baseline

Initialize the official LineageOS 22.2 manifest, then sync the crosshatch device
dependencies declared by its device tree. Record the manifest revision in every
Vault OS release; do not build from a moving branch without that release record.

The audited device baseline is:

- repository: `LineageOS/android_device_google_crosshatch`
- branch: `lineage-22.2`
- commit: `3716221d2f4101155e1b868437f34de343d0e52d`

Vault OS product files are kept as a separate overlay so upstream device work
can be reviewed and updated without maintaining a broad fork.

`lineage-22.2-pinned.xml` is generated by
`scripts/generate-pinned-manifest.sh`. The generator rejects unexpected dirty
repositories and replaces permitted unpublished framework commits with their
remote base revisions; Phone Vault and selectively imported GrapheneOS changes
are then reproduced from the attributed patch series rather than unreachable
manifest SHAs. Verify the adjacent `.sha256` file before use.
